# RoomTrack Web

A web application for managing room conditions and tracking assets that need attention.

Built with React, TypeScript, and Vite. Connects to the RoomTrack API.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
